# 综合影响分 v1

这是用于定位复盘重点的规则评分，不是实际胜率变化，也不是经过玩家总体数据校准的竞技等级。原有的击杀净值和“特了几个”保留；新分数另行计算。所有系数先使用完整比赛上下文计算，再按玩家、阵营、回合、地图与比赛筛选汇总。

## 击杀贡献

有效交战中的敌方枪械击杀：

`击杀贡献 = 1000 + 125 × 原加权击杀净值`

| 对位 | 原净值 | 击杀贡献 |
| --- | ---: | ---: |
| 同档枪械 | 0 | +1000 |
| 手枪击杀狙击枪 | +24 | +4000 |
| 长枪击杀狙击枪 | +4 | +1500 |
| 长枪击杀手枪 | −4 | +500 |
| 狙击枪击杀手枪 | −6 | +250 |

手枪、冲锋枪、长枪、狙击枪的**档位**分别为 1、2、3、4；原净值使用的**分值**仍为 1、2、5、7。霰弹枪、机枪归长枪。对手武器仍取死亡时手持，不用背包最高档枪替代。

受害者手持刀、道具等没有可比较枪档时，有效敌方枪械击杀仍获得 1000 基础贡献，不加入枪差奖励；武器证据缺失会明确标记。实际使用刀、电击枪、道具的击杀不获得本模块击杀贡献，但已完成的敌方击杀仍参与死前击杀计数和人数变化。

## 死亡扣分

`基础扣分 = round(1000 × 首死系数 × 枪差系数 × 人数系数 × 胜负系数 ÷ (1 + 0.6 × 死前击杀数))`

`死亡影响 = −(基础扣分 + 次回合装备变化附加)`

| 因素 | 取值 |
| --- | --- |
| 首死 | 本回合第一起有效死亡为 2，其他为 1；不是每队各自第一次死亡。 |
| 枪差 | `2^(本人死亡时手持枪档 − 实际击杀枪档)`；双方缺少可比较枪档时用中性 1，并注明依据。 |
| 人数 | 死亡前己方（含自己）与敌方人数相等为 1.25，不等为 0.75。 |
| 胜负 | 本方输为 1，赢为 0.35；未知胜负不猜测计分。 |
| 死前击杀 | 本回合死亡之前完成的有效敌方击杀数；队友击杀与自杀不算。每个已完成击杀都减轻后续死亡扣分。 |

不包含下回合附加时，正常 5v5 首死、死前零击杀且输掉回合：

| 死者手持 → 击杀枪械 | 基础扣分 |
| --- | ---: |
| 手枪 → 狙击枪 | −313 |
| 手枪 → 长枪 | −625 |
| 同档 → 同档 | −2500 |
| 长枪 → 手枪 | −10000 |
| 狙击枪 → 手枪 | −20000 |

这使 ECO 劣势对枪的首死成本较小，优势枪械输给小枪的首死成本显著增加。ECO 标签不会再重复乘一次：枪差负责刻画这次对枪的装备劣势，避免英雄枪或捡枪被整个队伍的经济类别掩盖。

## 次回合装备变化关联

只有相邻编号、同一半场、同一玩家和阵营、完整且可比较的开局装备，才加入这项。换边、加时重置、缺回合、最后一回合、快照缺失等情况跳过并说明原因。

枪械比较**死亡时实际手持枪械 → 下一回合冻结结束时携带的最高档枪械**，下一回合装备包含保枪和队友发枪。本回合 AK 开局、途中捡 AWP 并持 AWP 死亡，下一回合持 AK，会识别为降一档。死亡时手持刀或道具、或者武器证据缺失时，不凭背包或开局枪械猜测降档，也不追加这项。

道具数量比较本回合与下一回合冻结结束时的携带量；只有下一回合枪械相对死亡时手持枪械同档或更好时，才判断少带道具。

- 下一回合枪械降档：候选附加为 `150 × 降低档数 × max(1, 枪差系数)`。
- 下一回合枪械相对死亡时手持同档或更好，但道具更少：候选附加为 `60 × 减少颗数 × max(1, 枪差系数)`。
- 两项互斥，附加总额最多为基础扣分的 20%。少道具不会在已经判定枪械降档时再重复加罚。

缓存记录的是开局携带量，不是购买流水；因此这里描述的是**死亡后的装备变化关联**，不能证明死亡造成了全部损失。主动 ECO、发枪、战术配装等也会影响该项，复盘时应结合明细判断。

## 综合分与参考线

`综合影响分 = 击杀贡献累计 + 死亡影响累计`

`每回合综合分 = 综合影响分 ÷ 有效玩家回合数`

单个玩家每参与一个可计分回合贡献一个分母；多名玩家一起汇总时使用所有人的有效回合总和。因此跨场与跨人数比较应优先看每回合分，不直接比较累计分。

| 每回合综合分 | 暂定规则解释 |
| --- | --- |
| ≥ +500 | 优秀 / 强正向 |
| +200 至 < +500 | 良好 / 明显正向 |
| 0 至 < +200 | 轻度正向 |
| > −300 至 < 0 | 负向，优先复盘扣分事件 |
| ≤ −300 | 明显负向，存在较高死亡成本 |

**0 是这个模型的收支平衡线，不是平均玩家水平。** 这些阈值是人为设定的初版参考线，不是玩家百分位、真实胜率或客观实力结论。正式显示规则评级需要至少 30 个有效玩家回合、有效回合覆盖率达到 90%、至少一个可计分事件，且所选比赛没有缺失影响报告。否则显示“样本不足”或“证据不足”。玩家排行应结合各自样本量查看，不能靠合并多个小样本的总回合数推断其中某个人已经足够可靠。

此分数着重反映对枪收益和死亡成本，不完整衡量辅助道具、空间、信息、补枪与交易死亡、炸弹局势和战术职责；胜负乘数也会让队友表现影响个人分。适合找需要复盘的事件，不宜独立用于认定玩家水平。

## 数据边界与旧缓存

- 首死、死前击杀和人数从完整冻结阵容与有序死亡事件推导，并与可用回放帧核对。重复死亡事件不重复减人数；断线、异常复活、缺失死亡等造成不一致时不伪造人数。
- 新综合分只统计冻结结束至回合胜负确定期间。回合结束后追杀不再影响这个回合的综合分；原有击杀净值继续采用原口径，因此两张表的计分范围可能不同。
- 自杀、环境死亡、被队友击杀保留原因，不直接作为个人对枪惩罚；它们仍改变存活人数及首死顺序。
- 缺少可靠回合、阵容、人数或胜负时保留记录与原因，分数用未知而不是伪装成零。采样回退会显示近似来源。
- 影响分随统计规则版本从已有回放缓存派生，不重写录像缓存、比赛 ID、队伍分组或筛选。必要字段在旧缓存中缺失时，可使用已有的重新解析功能补充原始证据。
